# LeetCode Solutions

This repository contains my personal solutions to [LeetCode](https://leetcode.com/) problems.

The goal of this repository is to:

- **Brush up on problem-solving skills** by regularly practicing data structures and algorithms.
- **Strengthen fundamentals** by revisiting common algorithms, patterns, and techniques.
- **Explore other programming languages** by solving problems in languages I'm interested in learning or improving.

## A Note on Solutions

All solutions in this repository are written by me, without the use of AI tools or AI-generated solutions.

The idea is to work through each problem independently, figure things out along the way, and learn from the process, sincluding the mistakes.

Some solutions may not be the most optimal or elegant. That's part of the learning process, and I may revisit and improve them over time.

## Disclaimer

This is a personal learning repository, not a definitive collection of optimal solutions or a reference for others to copy.

Just documenting the journey, one problem at a time.
